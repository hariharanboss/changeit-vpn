Why ChangeIt VPN

A stealth VPN client engineered specifically for networks that block conventional VPN protocols.

🛡 Firewall-resilient

Wraps traffic in TLS 1.3 / WebSocket over port 443. Deep packet inspection (DPI) sees legitimate encrypted web traffic, not a VPN handshake.

🐧 Native Linux Support

How to install

Get connected in less than two minutes on any operating system.

🐧 Linux

  1. 1-Line Terminal Install (Recommended):
    curl -fsSL https://raw.githubusercontent.com/hariharanboss/changeit-vpn/main/changeit-desktop/install-linux.sh | bash
  2. Or Debian/Ubuntu .deb:
    sudo apt install ./ChangeIt-1.5.9-amd64.deb
  3. Or Portable AppImage:
    chmod +x ChangeIt-1.5.9-x86_64.AppImage && ./ChangeIt-1.5.9-x86_64.AppImage
  4. Launch ChangeIt from your app menu or terminal.

🖥 Windows

  1. Download ChangeIt-v1.5.9-Windows-x64.zip.
  2. Extract the entire ZIP archive to a folder (ensure bin folder is extracted alongside).
  3. Run ChangeIt.exe.
  4. Click Connect — the app validates the tunnel before enabling the system proxy.
  5. Use the [⟳] button in the header bar to check for future OTA updates.

📱 Android

  1. Download ChangeIt-arm64.apk (or Universal for older devices).
  2. Open the APK and permit “install from unknown sources” when prompted.
  3. Launch ChangeIt and accept the Android VPN permission prompt.
  4. Add the Home Screen Widget or long-press the app icon to add the widget directly.
  5. Tap connect. Disconnecting from the notification panel updates status instantly.

Frequently asked questions

Everything you need to know about ChangeIt VPN.

What is ChangeIt VPN?

ChangeIt VPN is a free, open-source VPN and stealth proxy client for Android, Windows, and Linux. It wraps traffic in TLS / WebSocket encrypted tunnels over port 443 so it resembles ordinary HTTPS browsing, helping it work on restrictive college, campus and enterprise networks.

Is ChangeIt VPN free?

Yes. ChangeIt VPN is completely free to download and use. The full source code is published under the MIT license on GitHub with zero ads or tracking.

Does ChangeIt VPN work on college or university WiFi?

It is specifically built for restrictive environments. Because the tunnel uses standard TLS / WebSocket on port 443, institutional firewalls cannot distinguish it from normal HTTPS traffic. The client validates the tunnel and automatically provides real-time diagnostics.

How does the Linux 1-line installer work?

The script automatically checks your distribution. On Debian, Ubuntu, Linux Mint, or Pop!_OS, it downloads and installs the native .deb package using dpkg. On other distributions (like Fedora, Arch, or openSUSE), it installs the standalone .AppImage into ~/.local/bin/changeit and configures a desktop launcher icon.

What is new in v1.5.9?

v1.5.9 adds full Linux support (1-line installer, native .deb, and AppImage), immediate notification disconnect synchronization on Android, clean long-press app shortcuts with direct widget pinning, manual check-for-updates button [⟳], and dynamic desktop version display.

Is ChangeIt VPN open source?

Yes. All source code for both the Desktop and Mobile clients is open source under the MIT license at github.com/hariharanboss/changeit-vpn.
