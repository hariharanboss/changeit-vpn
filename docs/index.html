Simple Setup Guides

Get connected in under two minutes on any operating system.

Windows Setup

  1. Download ChangeIt-Setup-1.5.9.exe.
  2. Double-click the installer — it installs automatically and places an icon on your Desktop.
  3. Launch ChangeIt and click Connect.
  4. The app verifies tunnel reachability before routing traffic.

Android Setup

  1. Download ChangeIt-arm64.apk (or Universal).
  2. Tap the APK to install; allow unknown sources if prompted.
  3. Launch app and accept Android's one-time VPN prompt.
  4. Long-press the app icon to pin the Home Widget.

Linux Setup

  1. Run the 1-line command in your terminal:
    curl -fsSL https://raw.githubusercontent.com/hariharanboss/changeit-vpn/main/changeit-desktop/install-linux.sh | bash
  2. Or install the deb: sudo apt install ./ChangeIt-1.5.9-amd64.deb
  3. Launch from application menu or terminal (changeit).

Frequently Asked Questions

Everything you need to know about ChangeIt VPN.

How do I install ChangeIt VPN on Windows?
Download ChangeIt-Setup-1.5.9.exe and double-click to install. It sets up everything automatically, adds desktop and Start menu shortcuts, and starts right away. If you prefer not to install anything on your system, download the portable ZIP instead.
What is ChangeIt VPN?
ChangeIt VPN is a free, open-source stealth VPN and proxy client for Windows, Android, and Linux. It wraps traffic in TLS / WebSocket encrypted tunnels over port 443 so it resembles ordinary HTTPS browsing, helping it work on restrictive college, campus and enterprise networks.
Is ChangeIt VPN free?
Yes. ChangeIt VPN is completely free to download and use. The full source code is published under the MIT license on GitHub with zero ads, tracking, or accounts.
Does ChangeIt VPN work on college or university WiFi?
It is specifically built for restrictive environments. Because the tunnel uses standard TLS / WebSocket on port 443, institutional firewalls cannot distinguish it from normal HTTPS traffic. The client validates the tunnel and automatically provides real-time diagnostics.
What is new in v1.5.9?
v1.5.9 introduces the native Windows 1-click .exe installer, official Linux support (1-line installer, native .deb, and AppImage), immediate notification disconnect synchronization on Android, clean long-press app shortcuts with direct widget pinning, manual check-for-updates button [⟳], and dynamic desktop version display.
